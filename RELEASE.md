# ClawRadar v1.0.0

ClawRadar is a lightweight security visibility dashboard for tracking publicly exposed OpenClaw instances.

It provides:

- A global map with zoom-based aggregation
- Country and city-level exposure insights
- IP lookup against the latest synced snapshot

This `v1.0.0` release is the final baseline release of the project.  
The repository is now in maintenance/frozen mode, and scheduled GitHub Actions sync has been removed.
