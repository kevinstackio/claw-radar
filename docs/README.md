# 文档导航

这个目录用于集中管理项目文档，建议优先从这里开始阅读。

## 文档列表

- [`PROJECT.md`](PROJECT.md)：项目描述、技术栈、目录分工与开发命令。
- [`FREE-AUTOMATION.md`](FREE-AUTOMATION.md)：免费方案下的自动采集、48 小时备份与地图打点（推荐 Netlas）。
- [`MCP.md`](MCP.md)：shadcn MCP 接入说明（客户端配置与项目约定）。
- [`SKILLS.md`](SKILLS.md)：shadcn Skills 接入说明（以及与 Codex 的关系）。
- [`ECHARTS.md`](ECHARTS.md)：ECharts 接入状态，以及 ECharts MCP/Skills 核查结果。
- [`CODEX-RULES.md`](CODEX-RULES.md)：本项目给 Codex 使用的特定规约。

## 使用方式

- 先读 `PROJECT.md` 了解项目背景。
- 需要免费自动化采集时，按 `FREE-AUTOMATION.md` 执行。
- 需要 AI 能力时，按 `MCP.md` 和 `SKILLS.md` 完成配置。
- 协作开发时，按 `CODEX-RULES.md` 执行。

## 包管理器约定

- 本项目仅允许使用 pnpm，请勿使用 npm 或 yarn。
